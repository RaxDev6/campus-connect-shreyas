# Campus Connect

Campus Connect is a simple, responsive student-events landing page by Shreyas. The interface uses a Material-inspired visual style with rounded surfaces, clear type, accessible contrast, and small interactive states.

## Technologies

- HTML5 for page structure and accessible content
- CSS3 for responsive layout and Material-inspired styling
- GitHub Pages for static website hosting

This project uses plain HTML and CSS. It does not use the Material UI JavaScript library, a build step, a backend, or a database.

## Hosting platform

GitHub Pages serves the files in this repository as a public website. It fits this static site because no server-side processing is needed, and source files and deployment settings stay together in GitHub.

## Requirements

- A GitHub account
- A browser
- The project files (index.html and this README.md)
- No API keys, secrets, paid services, or local server are required

## Run locally

1. Download or clone this repository.
2. Open index.html in a browser.
3. Edit index.html and refresh the browser to see changes.

## Reproducible deployment with GitHub Pages

1. Create a public GitHub repository and add index.html at the top level.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and / (root), then choose Save.
5. Wait for the Pages deployment to finish. GitHub displays the published address in Settings → Pages.
6. Open the address and check the page. For errors, check the repository's Actions tab and confirm Pages uses the branch and folder containing index.html.

## Setup and configuration

There are no secrets or environment variables. GitHub Pages serves static files from the selected branch and folder. To update the page, edit index.html and commit the change to main; Pages publishes it after deployment completes.
